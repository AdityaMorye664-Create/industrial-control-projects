# PLC & Industrial Automation Portfolio ![Human Written](https://img.shields.io/badge/Code-100%25_Human_Written-238636)
Welcome to my repository of Programmable Logic Controller (PLC) projects and automation algorithms developed in **CODESYS**. This portfolio demonstrates logic design, state machine implementation, and hardware integration for industrial environments.

## 🛠️ Technology Stack
+ **Languages (IEC 61131-3):** Structured Text (ST), Ladder Logic (LD), Function Block Diagram (FBD)
+ **Environment:** CODESYS V3.5
+ **Protocols & Edge Integration:** MQTT, UART, IoT Telemetry pipelines
+ **Hardware Domains:** Motor control, switchgear, embedded microcontroller interfacing

## 📂 Featured Projects

| Project Name | Language(s) | Description |
| :--- | :--- | :--- |
| [**01_Motor_Control_Logic**](./01_Motor_Control_Logic) | ST, LD | Start/stop sequences, interlocks, and fault handling for automated industrial motor systems. |
| [**02_MQTT_Telemetry_Gateway**](./02_MQTT_Telemetry_Gateway) | ST | PLC logic designed to format and transmit edge sensor data payloads to an MQTT broker. |
| [**03_Sequential_State_Machine**](./03_Sequential_State_Machine) | ST, FBD | Complex sequential process logic using CASE statements for equipment automation. |

*Note: Click on any project folder to view the source code and logic documentation.*

## 👀 How to View the Code
Since CODESYS `.project` files are binary, I have exported the core logic, Program Organization Units (POUs), and Global Variable Lists (GVLs) as `.xml` and `.st` text files. You can read the logic directly in your browser by clicking into the respective project folders.
